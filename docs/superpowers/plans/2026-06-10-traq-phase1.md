> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reframe traqcollective.com into a friendly, light, gradient-free AI-enablement site that captures and books leads, and fix the currently-broken production contact pipeline.

**Architecture:** Next.js 14 App Router site in `~/Downloads/TraqAI/site`, hosted on **Vercel** (project `nazirdogans-projects/traqcollective`, auto-deploys from GitHub `nazirdogan/TraqAI` on push). This phase rebuilds the design system (light, no gradients) and all home sections, reframes the intake, fixes Vercel env, adds AEO foundations, analytics, and legal pages.

**Tech Stack:** Next.js 14, TypeScript (strict), Tailwind, framer-motion, Resend, Anthropic SDK, Cloudflare Turnstile, Upstash, Vercel.

Routes/robots/schema verified with `curl`; email verified with a real submission; visuals reviewed on a Vercel preview deploy. Do NOT add a unit-test framework.

## Task 1: Fix the production email pipeline (standalone — do first, deploy immediately)

The live form is broken because the Vercel project has zero env vars. This task is independent of the redesign and should ship on its own so leads stop being lost. It works on `main` (no code change — config + redeploy only).

**Files:** none (Vercel config + redeploy).

- [ ] **Step 1: Confirm local values are present and correct**

Run:
```bash
cd ~/Downloads/TraqAI/site
sed -E 's/=.*/=<set>/' .env.local
grep -E '^(TEAM_INTAKE_EMAIL|FROM_EMAIL)=' .env.local
```
Expected: all 8 keys present; `TEAM_INTAKE_EMAIL` and `FROM_EMAIL` = `nazir@traqcollective.com`.

- [ ] **Step 2: Confirm folder is linked to the correct Vercel project**

Run: `cat .vercel/project.json`
Expected: project name resolves to `traqcollective` under `nazirdogans-projects`. If missing: `vercel link --yes --project traqcollective`.

- [ ] **Step 3: Push each production env var to Vercel**

For each key, pipe the local value into `vercel env add <KEY> production` (the command reads the value from stdin, avoiding it appearing in shell history):
```bash
cd ~/Downloads/TraqAI/site
for K in RESEND_API_KEY ANTHROPIC_API_KEY FROM_EMAIL TEAM_INTAKE_EMAIL \
         NEXT_PUBLIC_CLOUDFLARE_TURNSTILE_SITE_KEY CLOUDFLARE_TURNSTILE_SECRET_KEY \
         UPSTASH_REDIS_REST_URL UPSTASH_REDIS_REST_TOKEN; do
  V=$(grep -E "^$K=" .env.local | cut -d= -f2- | tr -d '"' | tr -d "'")
  printf '%s' "$V" | vercel env add "$K" production
done
```
Note: if any key already exists, Vercel will say so — that's fine, skip it.

- [ ] **Step 4: Verify all keys now present in production**

Run: `vercel env ls production`
Expected: all 8 keys listed under `production` (plus `NODE_VERSION` if present).

- [ ] **Step 5: Trigger a production redeploy (the `NEXT_PUBLIC_` Turnstile key is inlined at build)**

Run: `vercel --prod`
Expected: build succeeds, returns a production URL. Wait for "● Ready".

- [ ] **Step 6: Live end-to-end test — confirm a lead reaches the inbox**

On `https://traqcollective.com/#contact`, submit the quick form with a real test entry (e.g. first name "Test", last name "Lead", a deliverable email you control, company "Test Co", a one-sentence message, pick a service). Then:
- Confirm a **team notification** lands in `nazir@traqcollective.com` (subject `Quick-form lead: Test Lead @ Test Co`).
- Confirm a **confirmation email** lands at the address you entered.
- Open the AI chat, send one message, confirm it streams a reply (validates `ANTHROPIC_API_KEY`).

Expected: both emails arrive within ~1 minute; chat responds. If team email is missing, check Resend dashboard logs for the send and the `TEAM_INTAKE_EMAIL` value.

- [ ] **Step 7: Record the result**

Report to the user: which emails arrived, timestamps, and the Resend log status. If anything failed, stop and diagnose before continuing (most likely a mistyped env value).
